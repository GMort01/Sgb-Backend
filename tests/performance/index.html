Lectura principal

En la prueba de estrés, la latencia p95 aumentó de forma marcada desde aproximadamente 50 usuarios: cerca de 5,3 s a 50 y 13 s a 100. A 150 usuarios se observaron respuestas HTTP 500. Los datos muestran degradación bajo la carga probada; no identifican por sí solos si la causa fue Node.js, PostgreSQL, el pool de conexiones o el entorno de ejecución.

Conclusión: estos resultados corresponden a una prueba académica en un entorno local y de pruebas. No representan una medición de capacidad de producción. Para atribuir la causa de los HTTP 500 habría que contrastar estos datos con los logs de la API y las métricas de Supabase durante otra ejecución.
